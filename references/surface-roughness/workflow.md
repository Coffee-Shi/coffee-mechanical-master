# 表面粗糙度工作流

目标是给出一个首选 `Ra` 值（单位 `μm`），并说明功能依据、可行加工方法和需要核实的条件。优先选择能满足功能的最大 `Ra`，避免没有依据的过度精加工。

## 需要读取的资料

- 文字描述：读取 [selection-guide.md](selection-guide.md)，按表面功能分类。
- 图纸、照片、扫描件或 PDF：先声明需要提前安装 [text-to-cad](https://github.com/earthtojake/text-to-cad)，同时读取 [drawing-analysis.md](drawing-analysis.md)；借助 text-to-cad 的相关查看能力辅助定位目标表面。普通 JPG、PNG 和扫描 PDF 的像素识别仍由视觉能力完成。
- 需要核对原始 14 档数据、应用示例或旧等级表述：读取 [roughness-catalog.json](roughness-catalog.json)。
- 已能归入确定场景时，可运行 `../../scripts/roughness/recommend_ra.py --scenario <场景>`；脚本只做查表。

## 信息门禁

1. 先区分“读取图上已有标注”与“为未标注表面选新值”；不得静默改写已有标注。
2. 确认目标表面的零件和位置、是否运动接触、配合精度、密封方式、载荷/疲劳、润滑、材料、热处理、加工路线和尺寸范围。
3. 缺少会改变 Ra 档位的条件时，先问 1–3 个最关键问题，不先给唯一数值。用户明确要求快速估算时才能给“暂定值”，并列出假设和置信度。
4. 多项功能并存时按最严格功能选档，但确认该要求确实由粗糙度控制。尺寸、形位、波纹度、纹理方向和材料缺陷不能用更小的 Ra 代替。
5. 轴承、密封、液压、量规、高速摩擦或安全关键表面，要提示核对现行制造标准、供应商规范和最终图纸。

## 回答格式

- `信息充分性`：已确认条件及尚存假设。
- `首选粗糙度`：`Ra X μm`。
- `可接受备选`：仅在条件变化会导致相邻档位时给出。
- `为什么`：说明表面功能与档位依据。
- `建议工艺`：列出相容工艺，不承诺工艺名称本身即可达标。
- `还需确认`：只有确有会改变结论的问题时才列出。
- `知识库依据`：列出实际读取的本地参考文件。

不得使用未经确认的固定比例换算 `Ra` 与 `Rz`。源资料是用户提供的经验表，不是现行标准全文；重复示例和 E/D/G 级滚动轴承等旧表述必须要求核对现行标准。
