# 表面粗糙度选型指南

## 核心原则

`Ra` 数值越小，表面通常越光滑、成本越高。先确定功能约束，再选择满足约束的最大标准值。不能仅凭“重要”“高精度”或零件名称直接选值。

优先识别以下信息：

1. 是否为非配合面、静配合面、运动配合面或测量面。
2. 是否涉及定心、滚动轴承、滑动摩擦、密封、液压、疲劳、高速或高气密。
3. 已知尺寸公差/配合等级、直径范围和配套件等级。
4. 材料、热处理、涂层、腐蚀环境、润滑和预定加工方法。

## 经验档位

下表是用户提供资料的结构化摘要。使用 `Ra`，单位均为 `μm`。

| Ra | 典型功能 | 典型加工或表面状态 |
|---:|---|---|
| 100 | 极粗糙、无配合要求的毛坯或粗加工面 | 粗车、粗镗、粗刨、粗钻，明显刀痕 |
| 50 / 25 | 粗加工面、焊前焊缝、粗钻孔壁 | 粗加工，明显刀痕 |
| 12.5 | 一般非结合面、轴端面、倒角、齿轮/皮带轮侧面、键槽非工作面、减重孔眼 | 粗车、刨、铣、钻，可见刀痕 |
| 6.3 | 不重要配合面、支柱/支架/外壳/衬套/轴/盖端面、紧固件自由面、非定心螺纹面 | 车、镗、刨、钻、铣、铰、磨、粗铰、铣齿，可见加工痕迹 |
| 3.2 | 一般定心与配合面、键和键槽工作面、普通滚花/氧化前面；资料此档示例与 100 档有重复，按功能优先理解 | 车、镗、刨、铣、拉、磨、铰、滚压、铣齿，微见痕迹 |
| 1.6 | 保证定心与一般配合；普通滚动轴承配合、H7 孔、H8/H9 间隙孔、磨削齿面 | 精车/镗/铣、铰、拉、磨、滚压、细刮 |
| 0.8 | 较精确配合、轴承配合、IT7 级孔轴或中速传动轴等 | 铰、拉、磨、立铣、滚压、细刮，可辨纹理方向 |
| 0.4 | 长期保持稳定的配合、较高精度齿面、变应力重要件、橡胶密封件接触轴面、部分量规测量面 | 精铰、磨、精镗、拉、滚压、细刮 |
| 0.2 | 疲劳/耐久/防腐要求较高、气密面、精密支承与圆锥定心、IT5/IT6 配合、高精度齿面 | 布轮抛光、磨、研磨、超级加工，不可辨纹理方向 |
| 0.1 | 较大变应力、精确定心锥面、液压孔、汽缸套内表面、活塞销、仪器导轨、阀工作面 | 超级加工，暗光泽面 |
| 0.05 | 高气密配合、活塞/柱塞/汽缸面、摩擦离合器、精密同轴配合、滚动导轨和高速摩擦面 | 超级加工，亮光泽面 |
| 0.025 | 高压柱塞泵配合、中等精密仪器配合、精密量规测量面 | 超级加工，镜面光泽 |
| 0.012 | 仪器测量/配合面、大于 100 mm 块规工作面 | 超级加工，雾状镜面 |
| 0.0063 | 块规工作面、高精度测量面、高精度摩擦机构支承面 | 超级加工，雾状表面 |

## 决策优先级

从下到上确定最严格的必要条件：

1. 非功能/非配合表面：通常从 `Ra 12.5` 或 `6.3` 起选；毛坯或粗加工可更粗。
2. 一般配合或定心：通常在 `Ra 3.2-1.6`。
3. 较精确配合、普通轴承配合：通常在 `Ra 0.8-1.6`，结合配合等级、直径和轴承规范选择。
4. 长期稳定配合、密封接触、变应力：通常在 `Ra 0.4-0.2`。
5. 液压、精密定心、高气密、高速摩擦：通常在 `Ra 0.1-0.05`。
6. 量规、精密仪器、块规：通常在 `Ra 0.025-0.0063`，必须服从专用标准。

相邻档都可能成立时，给出一个首选值并把较细档写成有条件备选。例如：“首选 Ra 0.8 μm；若采用弹性唇形密封并要求长期低泄漏，则改为 Ra 0.4 μm，同时核对密封厂家对纹理方向的要求。”

## 常见误区

- 粗糙度不能替代尺寸公差、圆度、圆柱度、平面度或同轴度。
- 密封性能还受纹理方向、波纹度、材料孔隙、涂层和硬度影响。
- 轴承座/轴颈必须核对轴承厂家与配合标准；源资料中的 E/D/G 等级属于旧式表述。
- “镜面”是外观描述，不等价于某个唯一 Ra。
- 工艺名称只表示可达性范围；最终应通过测量验收。
