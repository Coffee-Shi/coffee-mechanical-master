# Coffee机械大师：极限与配合

一个“先确认信息、知识库优先、超出范围就明确拒答”的 Codex Skill。它会先判断用户给的数据能否唯一确定配合；信息不足时主动追问，只有把相邻方案排除后才推荐：

- 间隙、过渡或过盈配合；
- 孔/轴公差带及 IT 等级；
- 对应尺寸段的 IT 公差宽度；
- 能达到目标等级的加工路线；
- 基于资料表的相对成本 1 / 2.5 / 5 档。

Skill 的显示名是 **Coffee机械大师：极限与配合**，内部识别名为 `coffee-limits-and-fits`。

## 安装

将仓库中的 `skills/coffee-limits-and-fits` 目录复制到：

```text
$CODEX_HOME/skills/coffee-limits-and-fits
```

重启 Codex 后，可用以下方式调用：

```text
$coffee-limits-and-fits 直径20 mm，轴需要在孔内低速精密滑动，普通润滑油，需要经常拆装。
```

图纸或图片也可直接上传。Skill 会先提取尺寸、孔/轴和使用条件；识别不清的数字会请你确认，不会猜。

## 先问清楚，再给唯一结论

“用来做什么”和“直径多少”只是最低输入，不一定足够。例如只说“活塞在缸体内运动”，Skill 不会马上给出 `H7/g6`，而会继续确认：

- 往复速度、载荷、冲击和侧向力；
- 油/脂/无润滑以及工作温度；
- 密封由密封圈、油膜还是配合圆柱面承担；
- 圆柱面主要负责导向还是同时负责密封，以及所需导向精度。

定位连接会改问拆装频率、振动、装配方式和转矩路径；压入连接会改问材料、载荷、辅助紧固件、拆卸要求和装配能力。只要一个未知项仍可能改变配合家族，Skill 就只提问，不输出暂定公差代号。

## 严格知识库模式

输出必须能回溯到仓库内知识库。如果没有找到直接可用的配合，固定回复：

> 未在知识库中找到合适的公差配合，是否让人工智能自己思考。

只有用户明确同意，才能另行给出“AI 扩展推理”。

## 本地命令行查询

```powershell
python skills/coffee-limits-and-fits/scripts/fit_lookup.py `
  --diameter-mm 20 `
  --scene "低速精密滑动" `
  --connection moving `
  --motion "往复滑动" `
  --precision high `
  --speed low `
  --load light `
  --lubrication oil `
  --temperature stable `
  --sealing "由密封圈承担，圆柱面只导向"
```

资料不全时，脚本以退出码 `3` 返回待确认问题，不给推荐；知识库命中时以退出码 `0` 返回配合结果；资料齐全但知识库无解时以退出码 `2` 返回固定提示。结果包含匹配到的知识库场景、配合代号、孔/轴 IT 宽度、可达到的终加工方法和相对成本档。

## 知识库范围

- GB/T 1800.3—1998：IT01、IT0 及 IT1–IT18 标准公差宽度表；
- GB/T 1801—1999：孔、轴公差带的常用/优先选择原则；
- JIS B 0401（1998/1999 资料摘录）：常用基孔制、基轴制配合及常用尺寸偏差表；
- 公差等级的应用范围与典型应用；
- 加工方法能达到的 IT 范围、切削加工经济精度和不同公差等级的相对成本。

详细来源、版本和覆盖边界见 [`source-index.md`](skills/coffee-limits-and-fits/references/source-index.md)。

## 重要说明

- IT 数值是公差宽度，不等于上、下偏差。
- 本知识库保留来源中的标准版本，不声称已替代标准全文或当前版本。
- 成本 1 / 2.5 / 5 是资料中的相对比较档，不是价格报价，也不用于跨工厂的绝对成本比较。
