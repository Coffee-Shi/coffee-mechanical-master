# 图纸与图像分析

## 输入处理

- 对照片、截图和扫描图，先定位用户所指表面，再读取引出线、粗糙度符号、尺寸、公差、配合代号、基准、剖视图和技术要求。
- 对 PDF 图纸，渲染相关页面后检查；不要仅依赖文本抽取。
- 对 DXF、STEP/STP、STL、3MF 或机器人描述文件，如果 `cad-viewer` 可用，可用它查看几何与表面位置。几何只能帮助定位，不能单独证明密封、载荷、速度或配合要求。
- 图像分辨率不足时，要求用户提供目标区域近照或原始图纸，并明确当前识别的不确定字符。

## 两种任务必须分开

### 读取已有标注

1. 报告识别到的参数名称和值，例如 `Ra 1.6 μm`。
2. 说明引出线实际指向哪个面，以及是否为全周/全部表面/局部要求。
3. 若能识别，说明是否要求去除材料、禁止去除材料、纹理方向、加工余量或其他补充参数。
4. 不确定的符号或数字应标为不确定，不得自行补齐。

### 选择新值

1. 从图纸证据识别表面功能：轴颈、孔、端面、密封面、导轨、齿面、量规面等。
2. 读取配合代号（如 H7/h6）、公差等级、直径、材料和热处理。
3. 结合用户描述判断运动、载荷、速度、润滑、密封和寿命。
4. 用 `selection-guide.md` 选首选 Ra，并说明它是暂定推荐还是图纸已有要求。

## 证据等级与置信度

- **高：** 图纸明确给出粗糙度或专用技术要求，目标表面清楚。
- **中：** 图纸给出明确配合/公差且用户说明了功能，但没有粗糙度。
- **低：** 只有外观或几何，没有运动、密封、载荷、配合或工艺信息。

低置信度时也可给暂定值，但必须提出会改变档位的问题。优先追问：

1. 该面是否与另一零件配合或相对运动？
2. 是否承担密封、轴承、液压、疲劳或高速摩擦功能？
3. 配合等级、直径、材料/热处理和预定加工方法是什么？
